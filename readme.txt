== Description ==

**LinkGuardian** is an advanced, lightweight, and performance-optimized WordPress plugin that helps you keep your website free from broken or redirected links. Broken links can hurt your SEO rankings, frustrate users, and negatively affect conversions. LinkGuardian scans your entire site—including posts, pages, custom post types, and menus—to identify broken, redirected, or invalid URLs.

Whether you manage a blog, business website, portfolio, or WooCommerce store, LinkGuardian ensures your link structure stays clean, healthy, and optimized.

### 🔍 Key Features

* **Full-Site Link Scanning** – Scan posts, pages, custom post types, and menu links.
* **Internal & External Link Checking** – Detect issues both inside and outside your domain.
* **Broken Link Detection** – Identify 404s, timeouts, invalid URLs, and unreachable links.
* **Redirect Tracking** – Detect HTTP status codes (301, 302, 403, 500, etc.).
* **Real-Time AJAX Scanning** – Smooth, non-blocking scan progress.
* **Detailed Reports** – See broken, redirected, and valid links in a clean report table.
* **Link Management Tools** – Recheck links, view locations, and clear outdated results.
* **Optimized Performance** – Background processes ensure zero impact on frontend speed.
* **Developer-Friendly** – Clean, secure, and follows WordPress coding standards.
* **Data Cleanup Tools** – Enable optional “delete data on uninstall” functionality.
* **Modern Admin Interface** – Easy-to-use, intuitive dashboard interface.

### 🚀 Why Choose LinkGuardian?

Broken links can negatively impact:

- **SEO Ranking** – Search engines penalize sites with broken links.
- **User Experience** – Visitors lose trust when hitting dead ends.
- **Website Credibility** – Broken URLs reduce professional appeal.
- **Conversion Rates** – Faulty links can hurt sales and lead generation.

LinkGuardian helps you detect issues early and maintain a clean, optimized website.

== Installation ==

### 📦 Automatic Installation

1. Go to **Plugins → Add New**
2. Search for **LinkGuardian**
3. Click **Install Now**, then **Activate**

### 📥 Manual Installation

1. Download the plugin ZIP file.
2. Go to **Plugins → Add New → Upload Plugin**
3. Upload the ZIP and click **Install Now**
4. Activate the plugin

### ⚙️ Configuration

1. Open **LinkGuardian → Settings**
2. Select post types to scan
3. Enable/disable internal and external link checks
4. Configure cleanup and notification preferences
5. Save settings

== Frequently Asked Questions ==

### ❓ Will LinkGuardian slow down my website?
No. LinkGuardian uses optimized background processes and scans only when initiated manually. It has **zero impact** on frontend performance.

### ❓ Does the plugin support scheduled scans?
Not yet. Automated scanning is planned for future releases.

### ❓ Which types of links are scanned?
LinkGuardian scans:

- `<a>` links  
- Image sources (`<img src="">`)  
- Iframe URLs (`<iframe src="">`)  
- Script URLs (`<script src="">`)  
- Stylesheet links (`<link href="">`)  
- WordPress navigation menu links  

### ❓ Are navigation menus included?
Yes. Menu links are fully supported.

### ❓ Will my data be deleted on uninstall?
Only if you enable the **Delete data on uninstall** setting.

### ❓ Is LinkGuardian GDPR compliant?
Yes. The plugin does not collect personal data or send data to external servers.
